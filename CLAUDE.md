Working with the owner:

- Anything readers would see differently (layout, wording, pictures, new pages): build on a `preview-<name>`
  branch, screenshot desktop and phone, and wait for "publish". Invisible fixes can go straight to `main`.
- The owner deletes branches on GitHub; say which ones once a preview is published.
- No model names in commits or files. Never put the owner's name or email anywhere public or in outside requests.
- Check a data source's terms allow commercial use before adding it; never work around a site's blocks.
- Before saying something is live, check the live site.
- Most outside hosts are unreachable from this environment: test on GitHub Actions (see HANDOFF.md §8).
